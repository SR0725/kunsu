# BDD：官網 kunsu.app（銷售頁、註冊、登入連結、法律頁）

> PRD §31.6；設計參考 dub.co。2026-10-13。

## 場景

### 1. 首屏就能註冊
**Given** 訪客打開 kunsu.app　**When** 在首屏輸入 email 按「免費註冊」　**Then** 帳號服務寄出登入連結（client=web），畫面改成「去收信」，
不離開頁面；email 格式錯就在欄位下寫原因。首屏同時有「下載 Mac 版」與「App Store」入口（還沒上架的寫「即將推出」，不放假連結）。

### 2. 互動示範說服
**Then** 頁面有三個可以操作的示範，全部用假資料、不連網：
- **邊緣瀏海**：可以沿畫面邊緣拖曳，放開吸到最近的邊；滑過去會伸長並跑出題目；點一下打開決策面板，選答案後顯示回執、題數減一。
- **Station 主視窗**：側欄可以切換待決事項、歷史紀錄、督導、Agents、設定，內容跟著換。
- **手機 App**：一問一答自動播放，也可以自己點答案、撤回；往下拉圓圈填滿才出現歷史紀錄。
減少動態時不自動播放、沒有轉場；手機寬度下每個示範都能用手指操作，沒有水平捲動。

### 3. 隱私與開源說清楚
**Then** 有一段說明：內容只在你的 Mac、手機與 Mac 端對端加密、中轉站看不到、雲端只有 email 與裝置清單、程式碼開源（連到 GitHub）。

### 4. 登入連結
**Given** 信裡的連結 `kunsu.app/auth/verify?token=…`　**When** 打開　**Then** 自動完成登入：從 Mac／手機要求的就寫「回到 Kunsu」；
從網站註冊的就進到歡迎頁（下一步：下載 Mac 版、裝外掛、配對手機），歡迎頁可以登出與刪除帳號。連結失效寫「連結已失效，再寄一次」。

### 5. 法律與支援
**Then** 有隱私權政策、服務條款、支援頁（App Store 審查需要），頁尾每頁都連得到。

## 驗收清單

- [ ] AC-WEB-01 首屏註冊：送出 `/auth/email/start {client: web}`、去收信狀態、錯誤訊息（單元測試＋瀏覽器）
- [ ] AC-WEB-02 邊緣瀏海示範：拖曳吸邊（純函數單元測試）、hover 伸長、點開回答、題數減一（瀏覽器）
- [ ] AC-WEB-03 Station 示範側欄切換（單元測試＋瀏覽器）
- [ ] AC-WEB-04 手機示範：自動播放、點答案、撤回、下拉滿才出現歷史（純函數單元測試＋瀏覽器）
- [ ] AC-WEB-05 減少動態、手機寬度無水平捲動、鍵盤可操作（瀏覽器）
- [ ] AC-WEB-06 登入連結頁三種結果（單元測試＋瀏覽器）
- [ ] AC-WEB-07 歡迎頁：下一步、登出、刪除帳號（單元測試＋瀏覽器）
- [ ] AC-WEB-08 隱私權政策、服務條款、支援頁存在，頁尾連得到（建置檢查）
