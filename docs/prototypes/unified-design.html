電腦 · 主視窗與決策介面（點一列打開決策介面）
手機 App

一套語言，以主視窗為準

三個介面共用主視窗的顏色、字體、圓角和按鈕：中性灰、白色面板、細框線、Geist 字體。主要按鈕淺色是黑底、深色是白底。

顏色只剩一個

強調色只有藍色，用在選取、焦點和連結。紅黃綠只出現在小狀態標籤裡。Claude 和 Codex 的圖示是畫面上唯一的品牌色。

玻璃 = 浮在內容上面

手機底部的回覆面板與按鈕、電腦跳出來的決策介面、撤回提示用液態玻璃；主視窗的內容面板維持實心白色。玻璃只代表一件事：現在要你處理的。

唯一例外：邊緣瀏海

它要假裝是螢幕邊框的一部分，所以維持純黑。決策介面從瀏海長出來之後，就換成統一的玻璃面板。

長文案

  • 短選項：兩個大按鈕並排。
  • 選項長或有說明：一排一個，文字可換行。
  • 超過面板高度：按鈕區自己捲動，底部淡出並提示「往下還有選項」，輸入框固定在最下面。

沒有 Face ID

動錢的題目還是先跳出核對畫面（所見即所簽），按「批准並執行」就送出。其他送出都有 5 秒撤回。
